## ▶️ Testleri Çalıştırma



### Gereksinimler



- Android Studio

- Android Emulator veya gerçek cihaz



### Adımlar



1. Android Studio'da projeyi açın.

2. Android emülatörü başlatın (API 35 seçilebilir).

3. `app/src/androidTest/java/` dizinine gidin.

4. `MigrosE2ETest` üzerine sağ tıklayın.

5. Run butonuna basın.
